# ChemIntelAnalysis · ASAP 文献源接入说明

平台已预留 **设置 → ASAP 文献源** 的地址 / 凭据 / 连通性测试，但尚未猜测 ASAP 的检索与下载协议。要完成自动检索与入库，需要下面这些信息。

## 需要提供的接口信息

1. **Base URL** 与认证方式
   - Bearer Token / API Key header 名称
   - 是否需要额外 header、签名、时间戳
2. **检索接口**
   - 路径与 HTTP 方法
   - 查询参数：关键词、作者、DOI、年份、分页、排序
   - 请求示例（curl 或 JSON）
3. **返回结构**
   - 一篇文献的 JSON 示例
   - 标题、作者、通讯作者、机构、期刊、年份、DOI、摘要、PDF 链接分别位于哪些字段
   - 是否有全文 / PDF 的直接下载地址，是否需要二次请求
4. **PDF 下载**
   - 下载 URL 的形式
   - 认证方式与限流
   - 是否允许本地持久化
5. **限制**
   - QPS / 并发 / 每日额度
   - 是否需要机构网络或 IP 白名单
   - 错误码与重试建议
6. **可选**
   - 增量同步方式（按日期 / 游标）
   - Webhook 或导出文件
   - 主题 / 作者标识符体系

## 计划中的接入流程

```
ASAP 检索 → 结果列表 → 用户勾选 → 逐篇获取元数据 + PDF
        → 复用现有上传管线：SHA-256 去重、PDF 抽取、Crossref 补全（可选）
        → 规则情报抽取 → 技术栈建议 → 作者关联
```

复用点：

- `src/pdf.js`：PDF 文本与元数据抽取
- `src/analyzer.js`：动力学字段 / 技术栈建议 / 通讯作者推断
- `src/db.js`：文献、作者、技术栈入库
- `src/api.js`：新增 `/api/asap/search`、`/api/asap/import`
- `public/app.js`：检索 / 勾选 / 导入界面

## 安全约束

- 凭据只保存本地 SQLite，不写入导出文件。
- ASAP 下载的 PDF 仍会经过 SHA-256 去重与 PDF 魔数校验。
- PDF 与结构化情报默认只保存在本机。
- 若 ASAP 返回外链 PDF，会做 http/https 与内网地址校验。
