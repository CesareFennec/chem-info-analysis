# ChemIntelAnalysis

一个**本地优先**的文献情报与 PDF 管理工作台：上传论文，自动归档原文、抽取结构化情报、建立作者档案、按层级技术栈分类，并把批判判断持续积累下来。

面向理论化学 / 化学动力学 / 物理化学研究场景设计，但不限定学科。所有分析都在本地完成；不依赖外部大模型，也不会上传 PDF。

Repository: <https://github.com/CesareFennec/chem-info-analysis>

---

## 功能

| 能力 | 说明 |
|---|---|
| PDF 管理 | 上传、SHA-256 去重、本地归档、内嵌阅读、下载、替换、删除 |
| 全文抽取 | PDF.js 抽取文本；支持双栏阅读顺序；自动识别首页 DOI 与邮箱 |
| 核心五问 | 科学问题、方法、结论、局限、独立评估 |
| 化学动力学变量 | 哈密顿量、泛函、势函数、动力学方法、可观测量 |
| 证据与置信度 | 自动字段附原文引文与高/中/低置信度，可人工修改 |
| 公式排版 | 本地 WebTeX 将 LaTeX 渲染为 SVG，支持行内与独立公式 |
| 作者雷达 | 通讯作者识别、OpenAlex 同步、主页快照、最新动向时间线 |
| 技术栈 | 8 个初始方向；支持子分类、父子筛选、自动建议、增删改 |
| 批判记忆 | 立场、维度、严重度、证据、状态；按文献与作者聚合 |
| 数据管理 | JSON 导出、本地备份、SQLite 单文件数据库 |

## 快速开始

### Windows

1. 安装 **Node.js 22.5 或更高版本**：<https://nodejs.org/>
2. 解压项目到任意目录。
3. 双击 **`start-windows.bat`**。
4. 首次运行会自动安装依赖，随后打开 <http://127.0.0.1:3088>。

### WSL

```bash
cd /path/to/ChemIntelAnalysis
./start-wsl.sh
```

脚本会检查 Node 版本、安装依赖，并尝试调用 Windows 默认浏览器。若未自动打开，手动访问 <http://127.0.0.1:3088>。

建议把项目放在 WSL 的 Linux 文件系统中（例如 `~/research/ChemIntelAnalysis`），不要把 `node_modules` 和数据库放在 `/mnt/c/...`。

### Linux / macOS

```bash
./start.sh
# 或
npm install
npm start
```

### 手动启动 / 修改端口

```bash
npm install
PORT=3090 npm start          # Linux / WSL / macOS
set PORT=3090 && npm start   # Windows cmd
```

打开 `http://127.0.0.1:<PORT>`。

## 使用流程

1. **上传 PDF**：拖入文件；DOI、期刊、年份可留空，有 DOI 时自动查询 Crossref。
2. **核对元数据**：在文献详情「编辑信息」中修正标题、DOI、期刊、年份、技术栈与动力学判定。
3. **确认通讯作者**：进入「作者与通讯」页签。自动识别是线索，请对照 PDF 首页或投稿系统确认。
4. **补全情报**：规则抽取给出初稿；逐条核对原文证据，直接修改字段。公式可用 LaTeX 书写。
5. **追踪作者**：作者详情页「同步 OpenAlex」拉取主题、指标与最近论文；「抓取主页」保存主页快照。
6. **写批判**：在「批判记忆」页签记录质疑 / 存疑 / 支持，填写维度、严重度与证据。
7. **定期回看**：总览页「需要你的判断」会列出低置信、通讯作者待确认、存在开放批判的文献。

## 结构化情报

### 核心五问

- `scientific_question`：科学问题 / 缺口
- `methods`：方法与技术路线
- `conclusions`：结论与定量结果
- `limitations`：局限与未来工作
- `critical_assessment`：独立评估（最强证据、最弱环节、可复现性风险）

### 化学动力学理论变量

- `hamiltonian`：哈密顿量（模型形式、参数、自由度）
- `functional`：泛函（交换关联泛函、自由能泛函等，注明版本）
- `potential`：势函数 / 势能面（来源、拟合、验证、适用域）
- `dynamics_methods`：动力学方法（传播 / 采样 / 统计方法、系综、时间步长、边界条件）
- `observables`：可观测量（速率常数、截面、分支比、光谱、寿命、扩散系数等）

另有 `theory_framework`、`approximations`、`software`、`keywords`。

每个自动字段都有 `evidence`（原文逐字引文）与 `confidence`（高 / 中 / 低）。**自动结果始终需要人工复核**。

### 公式排版（WebTeX）

- 行内公式：`$...$` 或 `\(...\)`
- 独立公式：`$$...$$` 或 `\[...\]`
- 支持矩阵、分式、上下标、算符、`aligned`、`pmatrix` 等常见数学环境
- 由本地 WebTeX 渲染为 SVG，不依赖外部公式图片服务；同一公式有缓存
- 情报卡检测到公式时默认进入**公式阅读模式**；编辑模式下显示 LaTeX 源码与 WebTeX 预览
- 批判内容、作者画像与原文证据中的公式同样会渲染

如果公式没有渲染，检查是否用 `$...$` / `$$...$$` 包裹。PDF 抽取出的原始公式通常不带 LaTeX 定界符，需要人工补上。

## 作者雷达

### 通讯作者

- 上传时从 Crossref 作者列表与 PDF 中识别，按以下信号排序：
  1. PDF 中「Corresponding author / correspondence」附近的姓名（高置信）
  2. 联系邮箱 local-part 与姓、名、姓名缩写的匹配（高/中置信）
  3. 找不到明确信号时，按化学/物理惯例推断末位作者（低置信，页面明确标注“自动推断”）
- 文章作者页会显示推断来源与置信度；点击「重新识别通讯作者」可重跑。
- 手动确认后来源会变为“人工”，不会被增量分析覆盖。
- 同名作者按规范化姓名合并；当前不做机构消歧。

### OpenAlex 同步

在作者详情页点击「同步 OpenAlex」：

- 匹配作者（优先使用已填 OpenAlex ID / ORCID，否则按姓名 + 机构）
- 拉取论文数、被引、h-index、主题、最近论文
- 最近论文写入「最新动向」时间线（过滤数据集 / 软件 / 同行评审等非论文类型）
- 可填「学术联系人邮箱」，进入 OpenAlex polite pool

OpenAlex 可能滞后、匹配错人，或把同名作者合并。页面会保留来源，请自行判断。

### 主页抓取

填写作者主页 URL 后点击「抓取主页」：

- 只抓取静态 HTML 的标题、meta 描述与可见文本
- 拒绝本机 / 内网地址，限制重定向与响应大小
- 需要 JavaScript 渲染的主页只能得到有限内容
- 快照保存在作者档案中，不会反复自动抓取

## 技术栈

内置 8 个通用初始方向：

| 技术方向 | 说明 |
|---|---|
| 电子结构 | DFT、波函数方法、基组与电子相关 |
| 量子动力学 | 波包传播、路径积分与开放量子体系 |
| 分子动力学 | 经典/半经典轨迹、力场与采样 |
| 速率理论与统计动力学 | TST、RRKM、主方程与速率常数 |
| 机器学习势与数据驱动 | ML 势函数、代理模型与自动化 |
| 非绝热与光谱 | 激发态、锥形交叉与非绝热跃迁 |
| 实验化学动力学 | 时间分辨、分子束与反应器实验 |
| 多尺度与介观模拟 | kMC、粗粒化与跨尺度耦合 |

- 自动分类优先匹配当前分类的关键词；命中至少两个关键词，或一个高特异性短语/缩写时触发。
- 文章可以同时归入多个分类；按父级筛选会自动包含所有子类，父级计数自动汇总。
- 可新建顶层分类、添加子类、修改颜色/描述/关键词/排序。
- 删除父级会级联删除子类，但不会删除文献。
- 分类是内置初始值，可以按需调整；重启不会覆盖你的改动。

## 批判记忆

批判字段：

- **立场**：质疑 / 存疑 / 支持 / 批注
- **维度**：方法 / 数据 / 结论 / 可复现性 / 理论 / 表述 / 其他
- **严重度**：1–5
- **证据 / 位置**：页码、公式号、图中数据、对照文献
- **状态**：开放 / 已回应 / 已搁置

批判会显示在文献详情与「批判记忆」总览，按作者聚合到作者页，并永久保存在 SQLite，不随分析覆盖而丢失。

## PDF 与数据管理

```
data/
├── library.db          # SQLite：文献、作者、技术栈、批判、版本、设置
├── pdfs/               # 原始 PDF，文件名使用 UUID
├── backups/            # 手动备份 JSON
└── tmp/                # 上传临时文件
```

- 上传按 SHA-256 去重；重复 PDF 会返回已有文献编号。
- 单篇默认上限 100 MB，可设 `CHEMINTEL_MAX_UPLOAD_MB`。
- 扫描版 PDF 没有文本层，当前不含 OCR；可先外部 OCR 后再上传。
- 设置页可导出完整 JSON（含全文，体积较大）与创建本地备份。
- 完整备份 = 复制整个项目文件夹（至少 `data/`）。

### 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3088` | 服务端口 |
| `HOST` | `127.0.0.1` | 监听地址；改成 `0.0.0.0` 会暴露到局域网 |
| `CHEMINTEL_DATA_DIR` | `./data` | 数据目录 |
| `CHEMINTEL_MAX_UPLOAD_MB` | `100` | 单篇 PDF 上限 |
| `CHEMINTEL_OFFLINE` | 未设置 | 设为 `1` 时上传阶段跳过 Crossref 请求 |

旧版 `LIT_DATA_DIR` / `LIT_MAX_UPLOAD_MB` / `LIT_OFFLINE` 仍然兼容；新配置请使用 `CHEMINTEL_*`。

## ASAP 文献源连接

设置页提供 **ASAP 文献源**：

- 可保存服务地址与访问凭据
- 可测试连通性（HTTP 状态、耗时、响应预览）
- 不会伪造或猜测未公开的 API

当前尚未实现 ASAP 的检索、元数据映射与 PDF 下载，因为需要接口文档 / 示例响应。拿到后需要接入的位置：

- `src/api.js`：新增检索 / 导入路由
- `src/enrich.js`：ASAP 响应 → 平台元数据映射、PDF 下载
- `public/app.js`：检索结果选择 / 批量导入界面
- `src/db.js`：如需保存来源标识，可加字段

详见 [docs/ASAP_INTEGRATION.md](docs/ASAP_INTEGRATION.md)。

## 安全与边界

- 默认只监听 `127.0.0.1`，没有登录 / 权限系统，适合单机单用户。
- 不要把端口直接暴露到公网；如必须局域网访问，请加反向代理与认证。
- 主页抓取会阻止本机与常见内网地址，但仍建议只抓取你信任的公开页面。
- 自动抽取、Crossref、OpenAlex 均可能出错；平台保留原文证据与人工编辑入口，最终以论文原文为准。
- 只上传你有权访问和处理的文献，遵守出版商与机构许可。
- 公式端点限制输入长度并阻止 `\href`、`\includegraphics`、`\input` 等命令；SVG 作为图片加载，不执行脚本。

## 项目结构

```
server.js                 Express 启停与中间件
src/config.js             数据目录、端口、上传限制、离线模式
src/db.js                 SQLite schema、层级技术栈、聚合查询
src/pdf.js                PDF.js 文本 / 元数据 / DOI / 邮箱抽取
src/analyzer.js           规则抽取、动力学判定、技术栈建议、通讯作者推断
src/enrich.js             Crossref、OpenAlex、主页抓取（含 SSRF 防护）

src/api.js                REST API
src/taxonomy.js           层级技术栈初始数据
public/index.html         应用外壳
public/app.js             无构建步骤的前端 SPA（hash 路由）
public/styles.css         响应式样式
```

技术选择：Node.js 22+ 内置 `node:sqlite`，无需安装数据库；PDF.js 负责文本层；WebTeX 负责公式；前端零框架、零 CDN。

## 常见问题

**Q：启动时报端口被占用？**  
`PORT=3090 npm start`（Windows：`set PORT=3090 && npm start`）。

**Q：`node:sqlite` 报错 / 启动失败？**  
Node 版本低于 22.5。升级 Node 后删除 `node_modules` 重新 `npm install`。

**Q：WSL 里浏览器没打开？**  
手动访问 `http://127.0.0.1:3088`；Windows 浏览器和 WSL 的 localhost 默认互通。

**Q：PDF 上传后没有情报？**  
可能是扫描版或加密 PDF。看「原文 PDF」页签的抽取错误；先 OCR 或换文本版 PDF。

**Q：通讯作者识别错了？**  
在文献「作者与通讯」页签手动改，平台以人工保存结果为准。

**Q：公式没有渲染？**  
确认使用 `$...$` 或 `$$...$$` 包裹；PDF 原始文本通常不带 LaTeX 定界符。

**Q：能多人一起用吗？**  
当前是单用户本地应用，没有认证。多人使用需要自行加反向代理认证，或等待后续版本。
